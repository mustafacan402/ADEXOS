# 🎓 ADEXOS — Adaptive Exam Optimization System

## 📌 Overview

ADEXOS (Adaptive Exam Optimization System) is a project focused on improving the exam preparation process through adaptive learning and machine learning-based optimization.

The system aims to support personalized exam preparation by analyzing relevant data and adapting the learning or assessment process to individual needs.

## 🎯 Project Objectives

- Explore the application of machine learning to exam optimization.
- Support adaptive and personalized exam preparation.
- Apply software engineering principles to an AI-assisted educational system.
- Investigate data-driven approaches to improving exam preparation and assessment.

## 🛠️ Technologies

- **C# / ASP.NET** — Application and backend development
- **Python** — Machine learning and AI components
